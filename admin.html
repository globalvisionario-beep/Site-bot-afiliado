Como criar a chave
  1. No GitHub: foto do perfil, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o seu repositório.
  3. Em Permissions > Repository permissions: Contents = Read and write e Actions = Read and write.
  4. Gere, copie o token e cole aqui. Ele é guardado neste aparelho, protegido pela sua senha.
